# 随机上线 v2.2.3（正式版）· 从 v2.0.0 至今的完整更新

> **当前发布状态**：**正式版 v2.2.3**（Stable）。
> 市场在架版本为 **v2.0.0**，本次直接跨越 2.1 / 2.2 两个大版本线，下面按版本说明都改了什么。

## 一句话概括

从 v2.0.0 到 v2.2.3，这个插件做了三件事：**让它更懂你现在在做什么**（场景化唤醒）、**让它能自己检查更新并安全下载**（更新检测 + 原子写入）、**把界面和代码理干净**（UI 统一、代码拆成 6 个模块、修掉一批真 bug）。

## v2.2.3 —— 场景化唤醒（本次核心）

**解决的问题**：以前主动唤醒时，AI 会脱离当前剧情。比如角色本该在睡觉，它却回一句「想你了，你在忙吗」——因为话术库里只有 5 条通用搭讪，而且旧提示词写着「不要改变原意、不要增加新信息」，AI 只能照着改写，没法结合场景。

**改法**：

- **话术库 5 条 → 29 条，按场景分组**：`深夜/睡觉`、`清晨`、`上午`、`午休`、`下午`、`傍晚`、`晚间`、`不舒服`、`很久没回`。每条自带场景标签，按当前时间自动从对应组抽一条，发给 AI 前把标签剥掉。
- **唤醒提示词注入 `{时间}` 与 `{场景}`**：AI 现在知道「现在是 23:06，深夜，多半已经睡了或者躺着」。
- **话术只当「情绪方向参考」**：明确要求 AI「若参考句与当前状态冲突（例如你本该睡着却要热情搭话），按状态改写，宁可不照写」。
- **旧配置自动迁移**：升级时若你的提示词和话术还是旧默认（一字未改），自动换成新版；自己改过的不动。

**新增：唤醒联动温柔巡检的醋意值**

- 以前只有自动唤醒会累加醋意，手动点「立即唤醒」不计数。现在手动唤醒也计入（+8~12），多对话路径按档位 +8~20，单对话保持原有逻辑。
- 统一封顶 58，不会因为随机上线把你的应用藏起来。

## v2.2.2+1 —— 代码拆分为 6 个模块

- `on_air.js` 从 2904 行降到 1901 行，拆出 `update` / `holidays` / `prompts` / `config` / `chat` 五个模块。
- **功能、界面、行为零变化**，纯内部重构，方便后续维护。工具数量仍为 24 个。

## v2.2.2 —— 节假日换源 + 界面统一

- **节假日表换源（真 bug）**：旧数据源 `timor.tech` 已被 Cloudflare 拦截，返回 HTML 验证页 → JSON 解析必然失败 → 节假日表其实一直只能用内置的 2026 表。现改为 `holiday-cn` 静态 JSON，三路镜像依次尝试，并在面板显示分年计数（如「2026 年 N 天 · 2027 年 0 天（官方尚未公布）」）。
- **日期页交互修正**：点日历后的提示语改用「本次写入结果」判断，不再出现提示与实际相反。
- **统一配色与边框**：标题/正文/次要文字/按钮字色全部归到一套规则；次要按钮统一加描边；卡片底色从 4 种混用收敛成 1 种。
- **统一消息提示**：保存、拉节假日、手动触发、下载等操作都有 toast + 通知栏反馈，不再「点了没反应」。
- **主页刷新重做**：改为 onLoad 周期刷新 + 模块级缓存兜底。

## v2.2.1 —— 更新检查与下载加固

- **更新检查**：缓存里版本比当前旧会自动失效重拉（发版后不再念叨旧版本）；支持强制刷新；Release 正文清洗成纯文本摘要。
- **下载更新包**：失败重试 3 次（404 不重试、403 提示限流）；用资产大小校验字节数，不符报「文件不完整」并删残包；改成原子写入（`.part` → 校验 → 改名），中断不会留下坏包；磁盘不足有专门提示。
- **修复**：提示词页白屏两处、按钮共用 busy 导致整页变「…」、免打扰页重复的静默建议块。

## v2.2.0 —— 自动检查更新 + 主页瘦身

- 新增后端更新检测（版本比较、拉 Release、下载、跳过）；主页加更新横幅，三个按钮：**下载 / 稍后 / 跳过**。
- 主页从 7 张卡片瘦身为 3 张，视觉轻量化。

## v2.2.1+2 —— 一轮全面审计修复

- **下载**：模块级单例防连点、10 分钟自愈、失败返回带原因。
- **多对话**：每个对话各自计算沉默/冷却/未命中，不再互相干扰；角色卡入口从面板移除。
- **配置校验**：落盘剔除内部字段，允许系数为 0（原本会被当成非法）。
- **工作流**：阈值去硬编码，手动链重构。

## v2.1.2 —— 删掉「静默解除通知」

- **问题**：静默时段内任何工具调用都会检测「设备活动」，而它的判断依据之一是「对话窗口开着」→ 你正在说话时被误判成「沉默后活动」→ 系统通知被当成 user 消息发进对话，还白拉一整轮 AI 生成。
- **改法**：删掉 5 处调用，提示词页移除该项（字段保留以兼容老配置）。

## v2.1.1 —— 提示词「已改/默认」标识修正

- 「一键恢复默认」原来是把默认值写回字段 → 字段非空 → 永远显示「已改」。现改为清空字段，重置后能正确显示「默认」。

## v2.1.0 —— 心情账本

- 新增心情值（0-100，低落/平静/愉快/雀跃）、`get_mood` / `set_mood` / `mood_log` 三个工具，以及「用户回话 → 心情 +3」这类自动挂钩。

## 功能全景（v2.2.3 现状）

- **主动唤醒**：按 y=100f/(1+f) 算概率，f=a·x+b·x^c，你能改 a/b/c、沉默阈值、冷却时间。
- **两种话术模式**：`default`（AI 结合最近上下文自由发挥）/ `custom`（本地话术库）。v2.2.3 起两者都会带上场景。
- **发送通道**：A1（插件自己唤醒 AI）/ A2（借温柔巡检的自动回复）。
- **免打扰**：白天段 + 夜间段两段独立开关，支持节假日、学生模式、日期级静默、上学日自动静默。
- **节日日历**：内置节假日表 + 联网更新（现在真的能拉到了）。
- **提示词与话术全可改**：三组共 11 项，含档位话术库，带「已改/默认」标识与一键恢复。
- **控制台**：看关键读数、直接调接口。
- **更新检测**：自动检查、下载、跳过指定版本。
- **工具 24 个**：外部插件/工作流可直接调用，`api_docs` 能给完整文档。

## 升级方式

- 市场里更新本插件即可；已装旧版会提示更新（v2.2.0 起内置更新检测）。
- 配置兼容：老配置自动读取，提示词与话术若是旧默认会自动迁移到新版场景化版本；自己改过的保持原样。
